# 27 bài TypeScript OOP

Mỗi bài nằm trong một file riêng: `bai1.ts` ... `bai27.ts`.

## Chạy bằng Node.js + TypeScript

Cài TypeScript:
```bash
npm install -g typescript
```

Biên dịch toàn bộ:
```bash
tsc
```

Chạy một bài:
```bash
npx ts-node bai1.ts
```

Hoặc sau khi `tsc`:
```bash
node dist/bai1.js
```

File `giai-thich-27-bai.docx` chứa phần giải thích từng bài bằng tiếng Việt.
