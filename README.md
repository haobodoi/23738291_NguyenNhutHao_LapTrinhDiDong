# OOP Exercises - TypeScript

27 bài OOP theo đề bài.

## Yêu cầu

- Node.js 18+
- TypeScript
- VS Code / IntelliJ IDEA

## Cài đặt

```bash
npm install
```

## Compile toàn bộ

```bash
npm run build
```

## Chạy từng bài

Ví dụ câu 1:

```bash
npx ts-node src/exercise01.ts
```

Câu 2:

```bash
npx ts-node src/exercise02.ts
```

...

Câu 27:

```bash
npx ts-node src/exercise27.ts
```
